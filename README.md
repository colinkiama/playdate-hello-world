# Playate Hello World

Getting Familiar with the [Panic Playdate](http://play.date/).

The key files are the project and configuration files. Useful for setting up projects with well for you favourite editors.

## Easy Build instructions 

Use `make`

This will instally compile the game and open the simulator with the latest changes.

Very rapid development.

## Advanced build
